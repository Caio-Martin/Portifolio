Meu portfólio.
Da estrutura à publicação.

Um site estático para apresentar o perfil profissional, organizar projetos e facilitar o contato, com publicação automatizada no GitHub Pages.

01 / Contexto

Uma presença profissional simples de manter.

O objetivo do projeto é reunir competências, projetos e canais de contato em uma experiência responsiva. A arquitetura usa HTML, CSS e JavaScript, sem um framework de interface ou servidor de aplicação.

A estrutura mantém páginas independentes, estilos compartilhados e dados dos projetos em um único arquivo. O repositório registra o código, o histórico de alterações e os workflows de publicação.

02 / Implementação

Interface, conteúdo e operação.

  • Interface: navegação responsiva, tema claro e escuro, foco visível e conteúdo legível sem JavaScript.
  • Portfólio: conteúdo HTML gerado a partir de uma fonte única; o JavaScript acrescenta o carrossel.
  • Contato: envio pelo Web3Forms com feedback, prevenção de envios duplicados e tratamento de falhas.
  • Publicação: pacote estático validado e testes de interface antes do deploy pelo GitHub Actions.

03 / Evidências

Código aberto para conferir.

O código e a configuração dos testes estão disponíveis no repositório. Os workflows mostram o resultado de cada execução publicada. Os testes do formulário usam respostas simuladas, sem enviar mensagens reais.

Este caso documenta a implementação do próprio site. Não apresenta métricas de impacto comercial ou resultados de projetos de clientes.
